SupportPilot AI

Multi-tenant customer-support platform designed around secure organization boundaries and scalable ticket workflows.

TypeScript / Node.js
  • JWT authentication, refresh-token rotation, and role-based access control.
  • Organization-scoped data isolation with PostgreSQL and Prisma.
  • SLA monitoring, audit logs, idempotency protection, rate limits, and Redis-backed workers.
Key engineering decisions

Every request is scoped to an organization boundary. Slow or retryable work is moved to Redis-backed workers so ticket operations stay responsive, while audit events preserve an operational record.

Failure-Oriented System Test Framework

Linux-based fault-injection framework for understanding how distributed applications behave under adverse network conditions.

Python / Linux / tc-netem
  • Simulates network failure scenarios with Linux traffic control tools.
  • Measures p50, p95, and p99 latency for reliability analysis.
  • Turns observed network failures into concrete debugging signals.
Key engineering decisions

The framework treats failure conditions as inputs rather than exceptions. Latency percentiles make it possible to compare behavior across scenarios and identify tail-latency regressions.

Transformer Failure Analysis

Automated evaluation work investigating model failures on noisy Hinglish Reddit data.

Python / PyTorch
  • Compared MuRIL and mBERT behavior on multilingual, noisy inputs.
  • Investigated tokenization errors and inference limitations.
  • Built repeatable evaluation pipelines for analysis.
Key engineering decisions

Rather than treating accuracy as the only result, the evaluation pipeline isolates error sources in multilingual inference and tokenization for repeatable analysis.
